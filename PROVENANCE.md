# Asset Provenance & Data Standards

## Provenance Database
All entities generated by the pipeline are indexed in SQLite (`work/provenance.db`) and exported as machine-readable JSON files (`output/<map>/provenance.json`).

## Semantic Classifications
Every tracked entity is classified according to strict provenance standards:
* `VERIFIED_FROM_SOURCE`: Geometric entity extracted directly from source scan.
* `INFERRED_FROM_GEOMETRY`: Spatial footprint, roof height, or bounding enclosure.
* `AI_RECONSTRUCTED_INTERIOR`: Floor slabs, walls, doors, stairs, and furniture.
* `PROCEDURALLY_GENERATED`: Modular multi-tier trees, ground cover, PBR normal/roughness textures.
* `EXTERNAL_ASSET`: Standard library or runtime assets.
* `UNKNOWN`: Unverified elements (none present in final release).

## Tracked Fields
* `asset_id`: Unique identifier.
* `source_asset`: Source GLB filename.
* `source_hash`: SHA-256 hash of the input.
* `object_name`: Node/mesh designation.
* `semantic_class`: Classification tag.
* `confidence`: Inferred statistical confidence (0.0 - 1.0).
* `origin`: Generative algorithm or source scan.
* `model`: Underlying procedural or AI model.
* `runtime_status`: Verification status (`VERIFIED_ACTIVE`).
